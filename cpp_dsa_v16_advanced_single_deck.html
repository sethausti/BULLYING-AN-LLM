1. DP Fundamentals: What is DP?

Dynamic Programming solves problems by breaking them into overlapping subproblems and storing results to avoid recomputation. Two key properties required: optimal substructure means optimal solution contains optimal solutions to subproblems. Overlapping subproblems means the same subproblems appear multiple times. DP trades space for time.

// Naive Fibonacci - O(2^n)
int fib(int n) {
    if (n <= 1) return n;
    return fib(n-1) + fib(n-2);
}
Time: O(2^n)Space: O(n)

2. DP Fundamentals: Memoization Top-Down

Memoization is top-down DP that starts with the original problem and recursively breaks it down. We cache results in an array or map before returning to avoid recomputation. The recursion stack handles the dependency order automatically. This is often more intuitive to write first.

#include <vector>
using namespace std;

int fibMemo(int n, vector<int>& dp) {
    if (n <= 1) return n;
    if (dp[n] != -1) return dp[n];
    return dp[n] = fibMemo(n-1, dp) + fibMemo(n-2, dp);
}

int fib(int n) {
    vector<int> dp(n+1, -1);
    return fibMemo(n, dp);
}
Time: O(n)Space: O(n)

3. DP Fundamentals: Tabulation Bottom-Up

Tabulation is bottom-up DP that solves smallest subproblems first and builds up to the target. We fill a table iteratively without recursion. This avoids stack overflow and often has better cache locality. We must carefully determine the iteration order to ensure dependencies are ready.

int fibTab(int n) {
    if (n <= 1) return n;
    vector<int> dp(n+1);
    dp[0] = 0; dp[1] = 1;
    for (int i = 2; i <= n; i++) {
        dp[i] = dp[i-1] + dp[i-2];
    }
    return dp[n];
}
Time: O(n)Space: O(n)

4. DP Fundamentals: State Definition

State is the set of parameters that uniquely identify a subproblem. For Fibonacci, state is just n. For Knapsack, state is index and remaining capacity. A good state reduces dimensions and avoids redundant info. State space size directly impacts time and memory complexity.

// State: dp[i] = min coins to make amount i
// Transition: dp[i] = min(dp[i-coin] + 1) for all coins
int coinChange(vector<int>& coins, int amount) {
    vector<int> dp(amount+1, amount+1);
    dp[0] = 0;
    for (int i = 1; i <= amount; i++) {
        for (int coin : coins) {
            if (i >= coin) 
                dp[i] = min(dp[i], dp[i-coin] + 1);
        }
    }
    return dp[amount] > amount ? -1 : dp[amount];
}
Time: O(amount * coins)Space: O(amount)

5. DP Fundamentals: Transition Formula

Transition defines how to compute current state from previous states. It encodes the recurrence relation. For grid problems, dp[i][j] = dp[i-1][j] + dp[i][j-1]. For Knapsack, dp[i][w] = max(dp[i-1][w], val[i] + dp[i-1][w-wt[i]]). Correct transitions are key to correctness and optimization.

// 0/1 Knapsack transition
// dp[i][w] = max value using first i items, capacity w
int knapSack(int W, vector<int> wt, vector<int> val, int n) {
    vector<vector<int>> dp(n+1, vector<int>(W+1, 0));
    for (int i = 1; i <= n; i++) {
        for (int w = 1; w <= W; w++) {
            if (wt[i-1] <= w)
                dp[i][w] = max(val[i-1] + dp[i-1][w-wt[i-1]], 
                              dp[i-1][w]);
            else
                dp[i][w] = dp[i-1][w];
        }
    }
    return dp[n][W];
}
Time: O(nW)Space: O(nW)

6. DP Fundamentals: Overlapping Subproblems

Overlapping subproblems means the same subproblem is solved multiple times in naive recursion. DP caches these to compute once. Fibonacci fib(5) calls fib(3) twice. Visualizing a recursion tree helps identify overlaps. If no overlaps exist, divide-and-conquer is better than DP.

// Space Optimized Fibonacci - only store last 2
int fibOpt(int n) {
    if (n <= 1) return n;
    int prev2 = 0, prev1 = 1;
    for (int i = 2; i <= n; i++) {
        int curr = prev1 + prev2;
        prev2 = prev1;
        prev1 = curr;
    }
    return prev1;
}
Time: O(n)Space: O(1)

7. DP Fundamentals: Optimal Substructure

Optimal substructure means the optimal solution to a problem contains optimal solutions to its subproblems. Shortest path has this property: if A-B-C is shortest A to C, then A-B must be shortest A to B. Longest simple path lacks this property. We must prove this before applying DP.

// Matrix Chain Multiplication demonstrates optimal substructure
// dp[i][j] = min cost to multiply matrices i to j
int mcm(vector<int>& arr, int i, int j) {
    if (i == j) return 0;
    int minCost = INT_MAX;
    for (int k = i; k < j; k++) {
        int cost = mcm(arr, i, k) + mcm(arr, k+1, j) 
                   + arr[i-1] * arr[k] * arr[j];
        minCost = min(minCost, cost);
    }
    return minCost;
}
Time: O(n^3)Space: O(n^2)

9. 1D DP: Fibonacci Memoized

Fibonacci is the hello world of DP. Naive recursion runs in exponential time due to repeated calls. Memoization stores computed values in an array. State is single parameter n. Transition is f(n) = f(n-1) + f(n-2). Base cases f(0)=0, f(1)=1 break recursion.

int fibTopDown(int n, vector<int>& memo) {
    if (n <= 1) return n;
    if (memo[n] != -1) return memo[n];
    memo[n] = fibTopDown(n-1, memo) + fibTopDown(n-2, memo);
    return memo[n];
}
// Call: vector<int> memo(n+1, -1); fibTopDown(n, memo);
Time: O(n)Space: O(n)

10. 1D DP: Climb Stairs

You can climb 1 or 2 steps. Count ways to reach top step n. This is Fibonacci shifted: ways[n] = ways[n-1] + ways[n-2]. State dp[i] = ways to reach step i. Transition considers last move was 1-step or 2-step. Base: dp[0]=1, dp[1]=1.

int climbStairs(int n) {
    if (n <= 2) return n;
    vector<int> dp(n+1);
    dp[1] = 1; dp[2] = 2;
    for (int i = 3; i <= n; i++) {
        dp[i] = dp[i-1] + dp[i-2];
    }
    return dp[n];
}

11. 1D DP: House Robber

Rob houses in a line, cannot rob adjacent houses. Maximize money. State dp[i] = max money from houses 0 to i. Transition: either rob i and add to dp[i-2], or skip i and take dp[i-1]. Decision at each house depends on non-adjacent optimal. Base cases handle first two houses.

int rob(vector<int>& nums) {
    int n = nums.size();
    if (n == 0) return 0;
    if (n == 1) return nums[0];
    vector<int> dp(n);
    dp[0] = nums[0];
    dp[1] = max(nums[0], nums[1]);
    for (int i = 2; i < n; i++) {
        dp[i] = max(dp[i-1], nums[i] + dp[i-2]);
    }
    return dp[n-1];
}

12. 1D DP: Coin Change Min Coins

Given coins array and amount, find minimum coins to make amount. Unlimited supply of each coin. State dp[i] = min coins for amount i. Transition: try each coin, dp[i] = min(dp[i-coin] + 1). Initialize dp[0]=0, others to inf. If dp[amount] unchanged, impossible.

13. 1D DP: Max Subarray (Kadane's)

Find contiguous subarray with largest sum. Kadane's algorithm uses DP insight: dp[i] = max subarray ending at i. Transition: either extend previous or start new at i. dp[i] = max(nums[i], nums[i] + dp[i-1]). Track global max. This is space optimized 1D DP.

int maxSubArray(vector<int>& nums) {
    int currSum = nums[0], maxSum = nums[0];
    for (int i = 1; i < nums.size(); i++) {
        currSum = max(nums[i], currSum + nums[i]);
        maxSum = max(maxSum, currSum);
    }
    return maxSum;
}

14. 1D DP: Decode Ways

A message with '1'-'26' maps to 'A'-'Z'. Count ways to decode digit string. State dp[i] = ways to decode first i chars. Transition: if s[i] valid single digit, add dp[i-1]. If s[i-1,i] forms 10-26, add dp[i-2]. Handle '0' carefully as it can't stand alone.

int numDecodings(string s) {
    int n = s.size();
    if (n == 0 || s[0] == '0') return 0;
    vector<int> dp(n + 1);
    dp[0] = 1; dp[1] = 1;
    for (int i = 2; i <= n; i++) {
        int one = s[i-1] - '0';
        int two = stoi(s.substr(i-2, 2));
        if (one >= 1) dp[i] += dp[i-1];
        if (two >= 10 && two <= 26) dp[i] += dp[i-2];
    }
    return dp[n];
}

15. 1D DP: Jump Game II

Min jumps to reach last index where nums[i] is max jump length. Greedy BFS approach works in O(n), but DP view: dp[i] = min jumps to reach i. Transition: for j from i+1 to i+nums[i], dp[j] = min(dp[j], dp[i]+1). Optimized greedy tracks current reach and next reach.

int jump(vector<int>& nums) {
    int jumps = 0, currEnd = 0, farthest = 0;
    for (int i = 0; i < nums.size() - 1; i++) {
        farthest = max(farthest, i + nums[i]);
        if (i == currEnd) {
            jumps++;
            currEnd = farthest;
        }
    }
    return jumps;
}

17. 2D DP: Grid Unique Paths

Robot in m×n grid, moves only down or right. Count paths from top-left to bottom-right. State dp[i][j] = paths to reach cell i,j. Transition: dp[i][j] = dp[i-1][j] + dp[i][j-1]. Base: first row and col are 1. This is combinatorial C(m+n-2, m-1) but DP handles obstacles easily.

int uniquePaths(int m, int n) {
    vector<vector<int>> dp(m, vector<int>(n, 1));
    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            dp[i][j] = dp[i-1][j] + dp[i][j-1];
        }
    }
    return dp[m-1][n-1];
}

18. 2D DP: 0/1 Knapsack

Given weights and values, maximize value in knapsack of capacity W. Each item once. State dp[i][w] = max value using first i items, capacity w. Transition: if wt[i] <= w, max of include item or exclude. Else exclude only. Table filling order ensures subproblems ready.

int knapSack(int W, vector<int> wt, vector<int> val, int n) {
    vector<vector<int>> dp(n+1, vector<int>(W+1, 0));
    for (int i = 1; i <= n; i++) {
        for (int w = 1; w <= W; w++) {
            if (wt[i-1] <= w)
                dp[i][w] = max(val[i-1] + dp[i-1][w-wt[i-1]], 
                              dp[i-1][w]);
            else
                dp[i][w] = dp[i-1][w];
        }
    }
    return dp[n][W];
}

19. 2D DP: Longest Common Subsequence

Find length of longest subsequence common to two strings. Subsequence need not be contiguous. State dp[i][j] = LCS of text1[0..i-1] and text2[0..j-1]. Transition: if chars match, 1+dp[i-1][j-1]. Else max(dp[i-1][j], dp[i][j-1]). Base case empty string LCS is 0.

int longestCommonSubsequence(string text1, string text2) {
    int m = text1.size(), n = text2.size();
    vector<vector<int>> dp(m+1, vector<int>(n+1, 0));
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (text1[i-1] == text2[j-1])
                dp[i][j] = 1 + dp[i-1][j-1];
            else
                dp[i][j] = max(dp[i-1][j], dp[i][j-1]);
        }
    }
    return dp[m][n];
}

20. 2D DP: Edit Distance

Min operations to convert word1 to word2: insert, delete, replace. State dp[i][j] = min ops for word1[0..i-1] to word2[0..j-1]. Transition: if chars equal, dp[i-1][j-1]. Else 1 + min(insert dp[i][j-1], delete dp[i-1][j], replace dp[i-1][j-1]). Base: dp[i][0]=i, dp[0][j]=j.

int minDistance(string word1, string word2) {
    int m = word1.size(), n = word2.size();
    vector<vector<int>> dp(m+1, vector<int>(n+1));
    for (int i = 0; i <= m; i++) dp[i][0] = i;
    for (int j = 0; j <= n; j++) dp[0][j] = j;
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (word1[i-1] == word2[j-1])
                dp[i][j] = dp[i-1][j-1];
            else
                dp[i][j] = 1 + min({dp[i-1][j], dp[i][j-1], 
                                   dp[i-1][j-1]});
        }
    }
    return dp[m][n];
}

21. 2D DP: Minimum Path Sum

Grid with non-negative numbers, find path from top-left to bottom-right with min sum. Moves down or right only. State dp[i][j] = min sum to reach i,j. Transition: dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1]). Base: dp[0][0]=grid[0][0]. Can optimize to O(n) space using 1D array.

int minPathSum(vector<vector<int>>& grid) {
    int m = grid.size(), n = grid[0].size();
    vector<vector<int>> dp = grid;
    for (int i = 1; i < m; i++) dp[i][0] += dp[i-1][0];
    for (int j = 1; j < n; j++) dp[0][j] += dp[0][j-1];
    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            dp[i][j] += min(dp[i-1][j], dp[i][j-1]);
        }
    }
    return dp[m-1][n-1];
}
Time: O(mn)Space: O(1) if in-place

22. 2D DP: Subset Sum Problem

Given array and target sum, determine if subset exists with sum = target. State dp[i][j] = true if sum j possible using first i elements. Transition: dp[i][j] = dp[i-1][j] || dp[i-1][j-nums[i-1]]. Base: dp[i][0]=true, empty sum possible. Similar to 0/1 knapsack with boolean.

bool canPartition(vector<int>& nums) {
    int sum = accumulate(nums.begin(), nums.end(), 0);
    if (sum % 2) return false;
    int target = sum / 2;
    vector<bool> dp(target + 1, false);
    dp[0] = true;
    for (int num : nums) {
        for (int j = target; j >= num; j--) {
            dp[j] = dp[j] || dp[j - num];
        }
    }
    return dp[target];
}
Time: O(n*sum)Space: O(sum)

23. 2D DP: Table Filling Optimization

Many 2D DP can reduce to 1D if dp[i][j] depends only on prev row dp[i-1][*]. Knapsack becomes 1D by iterating w backwards to avoid overwriting. Space optimization trades clarity for memory. Rolling array uses two rows alternating. For LCS, two rows suffice.

// Space optimized 0/1 Knapsack
int knapSackOpt(int W, vector<int> wt, vector<int> val, int n) {
    vector<int> dp(W+1, 0);
    for (int i = 0; i < n; i++) {
        for (int w = W; w >= wt[i]; w--) {
            dp[w] = max(dp[w], val[i] + dp[w - wt[i]]);
        }
    }
    return dp[W];
}
Time: O(nW)Space: O(W)

25. DP on Strings: Palindrome Partitioning

Partition string such that every substring is palindrome. Return min cuts needed. State dp[i] = min cuts for s[0..i]. Transition: dp[i] = min(dp[j-1] + 1) if s[j..i] is palindrome. Precompute palindrome table isPal[i][j] in O(n^2). This is optimization over strings.

int minCut(string s) {
    int n = s.size();
    vector<vector<bool>> isPal(n, vector<bool>(n));
    vector<int> dp(n);
    for (int i = 0; i < n; i++) {
        int minCut = i;
        for (int j = 0; j <= i; j++) {
            if (s[j] == s[i] && (i-j <= 2 || isPal[j+1][i-1])) {
                isPal[j][i] = true;
                minCut = j == 0 ? 0 : min(minCut, dp[j-1] + 1);
            }
        }
        dp[i] = minCut;
    }
    return dp[n-1];
}
Time: O(n^2)Space: O(n^2)

26. DP on Strings: Word Break

Given string s and dictionary, determine if s can be segmented into words. State dp[i] = true if s[0..i-1] can be segmented. Transition: dp[i] = true if exists j < i such that dp[j] true and s[j..i-1] in dict. Use set for O(1) lookup. Check prefixes iteratively.

bool wordBreak(string s, vector<string>& wordDict) {
    unordered_set<string> dict(wordDict.begin(), wordDict.end());
    int n = s.size();
    vector<bool> dp(n + 1, false);
    dp[0] = true;
    for (int i = 1; i <= n; i++) {
        for (int j = 0; j < i; j++) {
            if (dp[j] && dict.count(s.substr(j, i-j))) {
                dp[i] = true;
                break;
            }
        }
    }
    return dp[n];
}

27. DP on Strings: Longest Palindromic Subsequence

Find longest subsequence that is palindrome. Different from substring. State dp[i][j] = LPS length in s[i..j]. Transition: if s[i]==s[j], 2+dp[i+1][j-1]. Else max(dp[i+1][j], dp[i][j-1]). Base: dp[i][i]=1. Fill table by increasing length. Equivalent to LCS(s, reverse(s)).

int longestPalindromeSubseq(string s) {
    int n = s.size();
    vector<vector<int>> dp(n, vector<int>(n));
    for (int i = n-1; i >= 0; i--) {
        dp[i][i] = 1;
        for (int j = i+1; j < n; j++) {
            if (s[i] == s[j])
                dp[i][j] = 2 + dp[i+1][j-1];
            else
                dp[i][j] = max(dp[i+1][j], dp[i][j-1]);
        }
    }
    return dp[0][n-1];
}

28. DP on Strings: Distinct Subsequences

Count distinct subsequences of s which equals t. State dp[i][j] = count of t[0..j-1] in s[0..i-1]. Transition: if s[i-1]==t[j-1], dp[i][j]=dp[i-1][j-1]+dp[i-1][j]. Else dp[i][j]=dp[i-1][j]. Base: dp[i][0]=1, empty t always match. This counts ways to form t.

int numDistinct(string s, string t) {
    int m = s.size(), n = t.size();
    vector<vector<long>> dp(m+1, vector<long>(n+1));
    for (int i = 0; i <= m; i++) dp[i][0] = 1;
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            dp[i][j] = dp[i-1][j];
            if (s[i-1] == t[j-1])
                dp[i][j] += dp[i-1][j-1];
        }
    }
    return dp[m][n];
}
Time: O(mn)Space: O(mn)

29. DP on Strings: Regular Expression Matching

Implement regex with '.' and '*'. '.' matches any char, '*' matches zero or more of preceding. State dp[i][j] = s[0..i-1] matches p[0..j-1]. bool isMatch(string s, string p) {
    int m = s.size(), n = p.size();
    vector<vector<bool>> dp(m+1, vector<bool>(n+1));
    dp[0][0] = true;
    for (int j = 1; j <= n; j++) {
        if (p[j-1] == '*') dp[0][j] = dp[0][j-2];
    }
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (p[j-1] == s[i-1] || p[j-1] == '.') {
                dp[i][j] = dp[i-1][j-1];

45. DP on Trees: Rerooting Technique Intro

Rerooting DP solves problem for tree rooted at every node. First DFS computes answer for arbitrary root. Second DFS reroots, moving root to each adjacent node, adjusting dp values by removing child contribution and adding parent contribution. Used for "sum of distances to all nodes" problems.

// Sum of distances to all nodes from each node
vector<int> sumOfDistancesInTree(int n, vector<vector<int>>& edges) {
    vector<vector<int>> g(n);
    for (auto& e : edges) {
        g[e[0]].push_back(e[1]);
        g[e[1]].push_back(e[0]);
    }
    vector<int> count(n, 1), ans(n, 0);
    function<void(int,int)> dfs1 = [&](int u, int p) {
        for (int v : g[u]) if (v != p) {
            dfs1(v, u);
            count[u] += count[v];
            ans[u] += ans[v] + count[v];
        }
    };
    function<void(int,int)> dfs2 = [&](int u, int p) {
        for (int v : g[u]) if (v != p) {
            ans[v] = ans[u] - count[v] + n - count[v];
            dfs2(v, u);
        }
    };
    dfs1(0, -1); dfs2(0, -1);
    return ans;
}
Time: O(n)Space: O(n)

49. AVL Trees: Self-Balancing Intro

AVL Tree is self-balancing BST where height difference of subtrees at most 1. Balance factor = height(left) - height(right), must be -1,0,1. Insertions may violate balance, rotations restore it. Guarantees O(log n) operations. Maintains height info at each node for O(1) balance check.

struct AVLNode {
    int key, height;
    AVLNode *left, *right;
    AVLNode(int k) : key(k), height(1), left(NULL), right(NULL) {}
};
int height(AVLNode* n) {
    return n ? n->height : 0;
}
int balanceFactor(AVLNode* n) {
    return n ? height(n->left) - height(n->right) : 0;
}
Height: O(log n)

50. AVL Trees: Rotations LL and RR

LL case: left-left heavy, right rotation at node. RR case: right-right heavy, left rotation. Rotation preserves BST property while reducing height. Right rotate: left child becomes parent. Left rotate: right child becomes parent. Update heights after rotation. These are single rotations.

AVLNode* rightRotate(AVLNode* y) {
    AVLNode* x = y->left;
    AVLNode* T2 = x->right;
    x->right = y;
    y->left = T2;
    y->height = max(height(y->left), height(y->right)) + 1;
    x->height = max(height(x->left), height(x->right)) + 1;
    return x;
}
AVLNode* leftRotate(AVLNode* x) {
    AVLNode* y = x->right;
    AVLNode* T2 = y->left;
    y->left = x;
    x->right = T2;

51. AVL Trees: Rotations LR and RL

LR case: left-right heavy, left rotate left child then right rotate node. RL case: right-left heavy, right rotate right child then left rotate node. Double rotations handle zigzag imbalance. After determining imbalance type, apply two single rotations. Restores AVL property.

AVLNode* insert(AVLNode* node, int key) {
    if (!node) return new AVLNode(key);
    if (key < node->key) node->left = insert(node->left, key);
    else if (key > node->key) node->right = insert(node->right, key);
    else return node;
    
    node->height = 1 + max(height(node->left), height(node->right));
    int balance = balanceFactor(node);
    
    // LL Case
    if (balance > 1 && key < node->left->key)
        return rightRotate(node);
    // RR Case
    if (balance < -1 && key > node->right->key)
        return leftRotate(node);
    // LR Case
    if (balance > 1 && key > node->left->key) {
        node->left = leftRotate(node->left);
        return rightRotate(node);
    }
    // RL Case
    if (balance < -1 && key < node->right->key) {
        node->right = rightRotate(node->right);
        return leftRotate(node);
    }
    return node;
}
Insert: O(log n)

58. Segment Tree: Build Operation

Build recursively: if leaf, tree[node]=arr[l]. Else build left [l,mid] and right [mid+1,r], combine results. For sum: tree[node] = tree[2*node] + tree[2*node+1]. Indexing: root at 1, left child 2*node, right 2*node+1. Full binary tree array representation.

        build(2*node, l, mid);
        build(2*node+1, mid+1, r);
        tree[node] = tree[2*node] + tree[2*node+1];

}

59. Segment Tree: Range Sum Query

Query [ql,qr]: if current segment [l,r] completely inside query, return tree[node]. If outside, return 0. Else query both children and sum. Recursion descends O(log n) nodes. Works because any range decomposes into O(log n) segments in tree.

int query(int node, int l, int r, int ql, int qr) {
    if (qr < l || r < ql) return 0; // outside
    if (ql <= l && r <= qr) return tree[node]; // inside
    int mid = (l + r) / 2;
    return query(2*node, l, mid, ql, qr) + 
           query(2*node+1, mid+1, r, ql, qr);
}

Time: O(log n)

60. Segment Tree: Point Update

Update index idx to value: find leaf, update, then update all ancestors on path to root. Recursion goes to leaf, on return recompute parent from children. Path length O(log n). For sum: tree[node] = tree[left] + tree[right] after updating child.

63. Segment Tree: Lazy Range Update

Range update [ul,ur] by val: if segment inside, add to lazy and push. If outside, return. Else update children and recalc node. Lazy ensure O(log n) update. Query must call push before reading node. This amortizes work, avoiding O(n) updates.

void updateRange(int node, int l, int r, int ul, int ur, int val) {
    push(node, l, r);
    if (ur < l || r < ul) return;
    if (ul <= l && r <= ur) {
        lazy[node] += val;
        push(node, l, r);
        return;

    int mid = (l + r) / 2;
    updateRange(2*node, l, mid, ul, ur, val);
    updateRange(2*node+1, mid+1, r, ul, ur, val);

}

65. Fenwick Tree / BIT: Introduction

Binary Indexed Tree computes prefix sums and updates in O(log n). Simpler than segment tree, less memory: O(n). Uses bit trick to isolate lowest set bit. Each index responsible for range of length lowbit(i). Prefix sum = sum of responsible nodes on path to root.

#define lowbit(x) ((x) & -(x))
// Or: x & -x in 2's complement
Space: O(n)

66. Fenwick Tree: Prefix Sum Query

Sum from 1 to i: add BIT[i], then i -= lowbit(i), repeat until i=0. Each step removes lowest 1-bit, jumps to parent responsible for previous range. Number of steps = bits in i, so O(log n). 1-indexed array required.

int BIT[MAXN];
int query(int i) {
    int sum = 0;
    while (i > 0) {
        sum += BIT[i];
        i -= lowbit(i);
    }
    return sum;
}
// Range sum [l,r] = query(r) - query(l-1)
Time: O(log n)

67. Fenwick Tree: Point Update

Update index i by delta: add delta to BIT[i], then i += lowbit(i), repeat while i ≤ n. This updates all nodes responsible for ranges containing i. Path length O(log n). Complement of query: add instead of subtract lowbit.

void update(int i, int delta) {
    while (i < MAXN) {
        BIT[i] += delta;
        i += lowbit(i);
    }
}
// Initialize: for i=1 to n, update(i, arr[i])
Time: O(log n)

68. Fenwick Tree: Build O(n)

Naive build O(n log n) by n updates. O(n) build: BIT[i] = arr[i], then for i=1 to n, j=i+lowbit(i), if j≤n then BIT[j] += BIT[i]. Each node adds its value to parent. This constructs tree bottom-up without redundant updates.

void build(vector<int>& arr) {
    int n = arr.size();
    for (int i = 1; i <= n; i++) BIT[i] = arr[i-1];
    for (int i = 1; i <= n; i++) {
        int j = i + lowbit(i);
        if (j <= n) BIT[j] += BIT[i];
    }
}
Time: O(n)

69. Fenwick Tree: Range Update Point Query

Range add [l,r] by val: BIT for difference array. Update(l, val), update(r+1, -val). Point query(i) gives arr[i]. Prefix sum of difference array is actual value. Enables range update, point query in O(log n), inverse of standard BIT.

// For range update, point query
void rangeUpdate(int l, int r, int val) {
    update(l, val);
    update(r + 1, -val);

70. Fenwick Tree: 2D BIT

2D BIT for submatrix sum. Update(x,y,delta): for i=x; i≤n; i+=lowbit(i), for j=y; j≤m; j+=lowbit(j), BIT[i][j]+=delta. Query(x,y): nested loops subtracting lowbit. Answers sum of rectangle (1,1) to (x,y). Submatrix by inclusion-exclusion.

int BIT2D[MAXN][MAXN];
void update2D(int x, int y, int delta) {
    for (int i = x; i < MAXN; i += lowbit(i))
        for (int j = y; j < MAXN; j += lowbit(j))
            BIT2D[i][j] += delta;
}

    int sum = 0;
    for (int i = x; i > 0; i -= lowbit(i))
        for (int j = y; j > 0; j -= lowbit(j))

}

73. Trie Advanced: Delete Word

Trie deletion: mark endOfWord=false, then recursively delete nodes with no children. If node has no children and not end of another word, remove it. Must traverse down to word end, then backtrack deleting. Prevents memory leaks. Returns bool if node should be deleted.

struct TrieNode {
    TrieNode* children[26];
    bool isEnd;
    TrieNode() : isEnd(false) {
        fill(begin(children), end(children), nullptr);
    }
};
bool isEmpty(TrieNode* node) {
    for (int i = 0; i < 26; i++) 
        if (node->children[i]) return false;
    return true;
}
TrieNode* remove(TrieNode* root, string key, int depth=0) {
    if (!root) return NULL;
    if (depth == key.size()) {
        root->isEnd = false;
        if (isEmpty(root)) {
            delete root;
            root = NULL;
        }
        return root;
    }
    int idx = key[depth] - 'a';
    root->children[idx] = remove(root->children[idx], key, depth+1);
    if (isEmpty(root) && !root->isEnd) {
        delete root;
        root = NULL;
    }
    return root;
}
Time: O(m)

78. Trie Advanced: XOR Maximum Pair

Given array, find max arr[i] XOR arr[j]. Insert binary representations into trie. For each number, greedily go opposite bit if exists to maximize XOR. 32-bit trie for ints. At each bit, choose 1 if current bit 0 and 1-branch exists, else 0. Accumulates max XOR path.

struct TrieBit {
    TrieBit* child[2];
    TrieBit() { child[0] = child[1] = NULL; }
};
void insertTrie(TrieBit* root, int num) {
    TrieBit* node = root;
    for (int i = 31; i >= 0; i--) {
        int bit = (num >> i) & 1;
        if (!node->child[bit]) node->child[bit] = new TrieBit();
        node = node->child[bit];
    }
}
int findMaxXOR(TrieBit* root, int num) {
    TrieBit* node = root;
    int maxXor = 0;
    for (int i = 31; i >= 0; i--) {
        int bit = (num >> i) & 1;
        if (node->child[1-bit]) {
            maxXor |= (1 << i);
            node = node->child[1-bit];
        } else {
            node = node->child[bit];
        }
    }
    return maxXor;
}

82. LCA Binary Lifting: Preprocessing

DFS to set depth[u] and up[u][0]=parent. Then up[u][k] = up[up[u][k-1]][k-1]. This DP builds 2^k ancestors from 2^(k-1) ancestors. Root parent is itself or -1. LOG = ceil(log2(n)). After this, any k-th ancestor query in O(log k).

void dfs(int u, int p, vector<vector<int>>& adj) {
    up[u][0] = p;
    for (int i = 1; i < LOG; i++) {
        up[u][i] = up[up[u][i-1]][i-1];
    }
    for (int v : adj[u]) {
        if (v != p) {
            depth[v] = depth[u] + 1;
            dfs(v, u, adj);
        }
    }
}

89. Bellman-Ford: SSSP with Negative Weights

Bellman-Ford computes single-source shortest path with negative edge weights. Dijkstra fails with negatives. Idea: relax all edges V-1 times. After k iterations, shortest path with ≤k edges found. If V-th iteration changes distance, negative cycle exists. Detects negative cycles reachable from source.

struct Edge { int u, v, w; };
// Returns false if negative cycle
bool bellmanFord(int n, int src, vector<Edge>& edges, vector<int>& dist) {
    dist.assign(n, INT_MAX);
    dist[src] = 0;
    for (int i = 0; i < n-1; i++) {
        for (auto e : edges) {
            if (dist[e.u] != INT_MAX && dist[e.u] + e.w < dist[e.v])
                dist[e.v] = dist[e.u] + e.w;
        }
    }
    for (auto e : edges) {
        if (dist[e.u] != INT_MAX && dist[e.u] + e.w < dist[e.v])
            return false; // negative cycle
    }
    return true;
}
Time: O(VE)Space: O(V)

92. Bellman-Ford: SPFA Optimization

Shortest Path Faster Algorithm uses queue, only relax edges from updated vertices. Best case O(E), worst O(VE). Not reliable complexity but fast in practice on random graphs. Still detects negative cycles if node enqueued ≥ n times. Queue optimization over full relaxation.

bool spfa(int n, int src, vector<vector<pair<int,int>>>& adj, vector<int>& dist) {
    dist.assign(n, INT_MAX);
    vector<int> cnt(n, 0);
    vector<bool> inQueue(n, false);
    queue<int> q;
    dist[src] = 0; q.push(src); inQueue[src] = true;
    while (!q.empty()) {
        int u = q.front(); q.pop(); inQueue[u] = false;
        for (auto [v, w] : adj[u]) {
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                if (!inQueue[v]) {
                    q.push(v); inQueue[v] = true;
                    if (++cnt[v] >= n) return false; // neg cycle
                }
            }
        }
    }
    return true;
}
Avg: O(E)Worst: O(VE)

97. Floyd-Warshall: All-Pairs Shortest Path

Floyd-Warshall finds shortest paths between all pairs. DP approach: dist[k][i][j] = shortest i to j using vertices 1..k as intermediates.                 if (dist[i][k] < INF && dist[k][j] < INF)
                    dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]);
            }
        }
    }
}

1. Initialize key[v]=INF for all, key[src]=0. 2. Priority queue of (key, vertex). 3. While PQ not empty: extract min u, add to MST, for each neighbor v of u not in MST, if weight(u,v) 

typedef pair<int,int> pii;
vector<int> prim(int n, vector<vector<pii>>& adj) {
    vector<int> key(n, INT_MAX);
    vector<bool> inMST(n, false);
    vector<int> parent(n, -1);
    priority_queue<pii, vector<pii>, greater<pii>> pq;
    key[0] = 0; pq.push({0, 0});
    while (!pq.empty()) {
        int u = pq.top().second; pq.pop();
        if (inMST[u]) continue;
        inMST[u] = true;
        for (auto [v, w] : adj[u]) {
            if (!inMST[v] && w < key[v]) {
                key[v] = w;
                pq.push({key[v], v});
                parent[v] = u;
            }
        }
    }
    return parent;
}
Time: O(E log V)Space: O(V)

121. Max Flow Ford-Fulkerson: Introduction

Flow network: directed graph with capacities. Max flow from source to sink. Ford-Fulkerson: find augmenting path in residual graph, push bottleneck flow, repeat until none. Residual graph has forward and backward edges. Backward edge allows undoing flow.

122. Max Flow: Residual Graph

Residual graph shows remaining capacity. For edge u->v with flow f, residual u->v = cap - f, v->u = f. Push flow along path reduces forward residual, increases backward. Allows algorithm to cancel previous choices. Augmenting path is s->t path with positive residual capacity.

// If flow 3/10 on u->v, residual: u->v=7, v->u=3

123. Max Flow: Augmenting Path

Find path s to t with min residual > 0 using DFS or BFS. DFS gives Ford-Fulkerson, BFS gives Edmonds-Karp O(VE^2). Bottleneck = min residual on path. Augment flow by bottleneck, update residuals. Repeat until no path. Maintains capacity constraints, flow conservation.

int bfs(int s, int t, vector<int>& parent, vector<vector<int>>& res) {
    fill(parent.begin(), parent.end(), -1);
    parent[s] = -2;
    queue<pair<int,int>> q;
    q.push({s, INT_MAX});
    while (!q.empty()) {
        int u = q.front().first;
        int flow = q.front().second;
        q.pop();
        for (int v = 0; v < res.size(); v++) {
            if (parent[v] == -1 && res[u][v] > 0) {
                parent[v] = u;
                int newFlow = min(flow, res[u][v]);
                if (v == t) return newFlow;
                q.push({v, newFlow});
            }
        }
    }
    return 0;
}

124. Max Flow: Edmonds-Karp BFS

Edmonds-Karp uses BFS for shortest augmenting path. Guarantees O(VE^2). Each BFS O(E), at most O(VE) augmentations. Shortest path length non-decreasing. Suitable for general graphs. Avoids pathological DFS cases. Use adjacency matrix or list with residual capacities.

int edmondsKarp(int n, int s, int t, vector<vector<int>> cap) {
    vector<vector<int>> res = cap;
    vector<int> parent(n);
    int maxFlow = 0, newFlow;
    while (newFlow = bfs(s, t, parent, res)) {
        maxFlow += newFlow;
        int v = t;
        while (v != s) {
            int u = parent[v];
            res[u][v] -= newFlow;
            res[v][u] += newFlow;
            v = u;
        }
    }
    return maxFlow;
}
Time: O(VE^2)

137. KMP Algorithm: Prefix Function Intro

Knuth-Morris-Pratt finds all occurrences of pattern in text in O(n+m). Key: prefix function π[i] = length of longest proper prefix of pattern[0..i] which is also suffix. Avoids rechecking characters on mismatch. Failure function jumps to next possible match position using π.

// π[i] = max k < i+1 such that p[0..k-1] = p[i-k+1..i]
Time: O(n+m)Space: O(m)

138. KMP Algorithm: Compute Prefix Function

Build π array: for i=1 to m-1, j=π[i-1]. While j>0 and p[i]!=p[j], j=π[j-1]. If match, j++. π[i]=j. Smartly reuses previous computations. Amortized O(m). π encodes borders of prefixes. Example: "abababca" π=[0,0,1,2,3,4,0,1].

vector<int> prefixFunction(string s) {
    int n = s.size();
    vector<int> pi(n);
    for (int i = 1; i < n; i++) {
        int j = pi[i-1];
        while (j > 0 && s[i] != s[j]) j = pi[j-1];
        if (s[i] == s[j]) j++;
        pi[i] = j;
    }
    return pi;
}
Time: O(m)

139. KMP Algorithm: Pattern Matching

Search text using π of pattern. Maintain j = length of current match. For each text[i], while j>0 and text[i]!=pat[j], j=π[j-1]. If match, j++. If j==m, found occurrence at i-m+1, reset j=π[j-1] for next. No backtrack in text, O(n) scan.

vector<int> kmpSearch(string text, string pat) {
    vector<int> pi = prefixFunction(pat);
    vector<int> res;
    int j = 0;
    for (int i = 0; i < text.size(); i++) {
        while (j > 0 && text[i] != pat[j]) j = pi[j-1];
        if (text[i] == pat[j]) j++;
        if (j == pat.size()) {
            res.push_back(i - j + 1);
            j = pi[j-1];
        }
    }
    return res;
}

    for (int i = 0; i < m; i++) {

154. Z-Algorithm: Z-Box Technique

Maintain interval [L,R] where s[L..R] = prefix s[0..R-L]. If i ≤ R, initialize Z[i] = min(R-i+1, Z[i-L]). Then expand while s[Z[i]]==s[i+Z[i]]. If i+Z[i]-1 > R, update L=i, R=i+Z[i]-1. This avoids redundant comparisons, linear time.

vector<int> zFunction(string s) {
    int n = s.size();
    vector<int> z(n);
    int L = 0, R = 0;
    for (int i = 1; i < n; i++) {
        if (i <= R) z[i] = min(R - i + 1, z[i - L]);
        while (i + z[i] < n && s[z[i]] == s[i + z[i]]) z[i]++;
        if (i + z[i] - 1 > R) L = i, R = i + z[i] - 1;
    }
    return z;
}

Search pattern P in text T: form S = P + '#' + T, compute Z. Positions i where Z[i] = |P| correspond to matches in T at i - |P| - 1. '#' sentinel ensures Z doesn't cross boundary. Z-algo code shorter than KMP, same complexity.

vector<int> searchZ(string text, string pat) {
    string s = pat + "#" + text;
    vector<int> z = zFunction(s);
    vector<int> res;
    for (int i = pat.size() + 1; i < s.size(); i++) {
        if (z[i] == pat.size()) res.push_back(i - pat.size() - 1);
    }
    return res;
}

157. Z-Algorithm: Distinct Substrings Count

int countDistinctSubstrings(string s) {

        for (int j = 1; j < t.size(); j++) maxZ = max(maxZ, z[j]);

    return total;

162. Manacher's: Transform String

Insert '#' to make uniform: all palindromes odd length in transformed string. Example: "abba" -> "#a#b#b#a#", P=[0,1,0,1,4,1,0]. Center at index 4, radius 4, corresponds to "abba". Length in original = P[i]-1. Start index = (i-P[i])/2.

string transform(string s) {
    string t = "#";
    for (char c : s) {
        t += c;
        t += '#';
    }
    return t;
}

163. Manacher's: Core Algorithm

Maintain center C and right boundary R of rightmost palindrome. If iR, update C=i, R=i+P[i]. Each char compared O(1) amortized. R only increases, total O(n).

vector<int> manacher(string s) {
    string t = transform(s);
    int n = t.size();
    vector<int> P(n, 0);
    int C = 0, R = 0;
    for (int i = 1; i < n-1; i++) {
        int mirr = 2*C - i;
        if (i < R) P[i] = min(R - i, P[mirr]);
        while (i + P[i] + 1 < n && i - P[i] - 1 >= 0 && 
               t[i + P[i] + 1] == t[i - P[i] - 1])
            P[i]++;
        if (i + P[i] > R) {
            C = i;
            R = i + P[i];
        }
    }
    return P;
}
Time: O(n)

164. Manacher's: Extract Answer

Find max P[i], compute start = (i - P[i]) / 2, length = P[i]. This gives longest palindromic substring in original. Also count all palindromes: sum((P[i]+1)/2). Manacher gives radius at each center, enabling range queries on palindromes.

string longestPalindrome(string s) {
    auto P = manacher(s);
    int maxLen = 0, center = 0;
    for (int i = 0; i < P.size(); i++) {
        if (P[i] > maxLen) {
            maxLen = P[i];
            center = i;
        }
    }
    int start = (center - maxLen) / 2;
    return s.substr(start, maxLen);
}

170. Suffix Array: O(n log^2 n) Build

Doubling algorithm: sort by first 1,2,4,8... chars. Rank pairs (rank[i],rank[i+k]). Use radix sort for O(n log n). After log n iterations, ranks distinct, suffixes sorted. Compression of characters to ranks avoids string compares. k doubles each round.

vector<int> buildSA(string s) {
    int n = s.size();
    vector<int> sa(n), rnk(n);
    for (int i = 0; i < n; i++) {
        sa[i] = i;
        rnk[i] = s[i];
    }
    for (int k = 1; k < n; k *= 2) {
        auto cmp = [&](int i, int j) {
            if (rnk[i] != rnk[j]) return rnk[i] < rnk[j];
            int ri = i + k < n ? rnk[i + k] : -1;
            int rj = j + k < n ? rnk[j + k] : -1;
            return ri < rj;
        };
        sort(sa.begin(), sa.end(), cmp);
        vector<int> tmp(n);
        tmp[sa[0]] = 0;
        for (int i = 1; i < n; i++)
            tmp[sa[i]] = tmp[sa[i-1]] + cmp(sa[i-1], sa[i]);
        rnk = tmp;
    }
    return sa;
}
Time: O(n log^2 n)

171. Suffix Array: LCP Array Kasai

LCP[i] = longest common prefix of sa[i] and sa[i-1]. Kasai's algorithm computes LCP in O(n) using lcp[rank[i]] ≥ lcp[rank[i-1]]-1. suffix array + LCP enables O(1) LCP query with RMQ. LCP useful for distinct substrings, longest repeated substring.

vector<int> buildLCP(string s, vector<int>& sa) {
    int n = s.size();
    vector<int> rnk(n), lcp(n);
    for (int i = 0; i < n; i++) rnk[sa[i]] = i;
    int h = 0;
    for (int i = 0; i < n; i++) {
        if (rnk[i] > 0) {
            int j = sa[rnk[i] - 1];
            while (i + h < n && j + h < n && s[i + h] == s[j + h]) h++;
            lcp[rnk[i]] = h;
            if (h > 0) h--;
        }
    }
    return lcp;
}
Time: O(n)

172. Suffix Array: Substring Search

Search pattern P: binary search on sa. Compare P with suffix at sa[mid]. O(m log n). Find lower_bound and upper_bound, count occurrences = ub-lb. Faster than KMP for multiple queries after O(n log n) preprocess. LCP speeds up to O(m + log n).

int lowerBound(string& s, vector<int>& sa, string& p) {
    int l = 0, r = sa.size();
    while (l < r) {
        int mid = (l + r) / 2;
        if (s.compare(sa[mid], p.size(), p) < 0) l = mid + 1;
        else r = mid;
    }
    return l;
}
Query: O(m log n)

174. Suffix Array: Distinct Substrings Count

Total substrings = n*(n+1)/2. Subtract duplicates: each LCP[i] counts duplicates with previous. Distinct = n*(n+1)/2 - sum(lcp[i]). Suffix array gives O(n) solution after build. Example: "banana" has 15 distinct.

long long countDistinct(string& s, vector<int>& sa, vector<int>& lcp) {

    long long total = n * (n + 1) / 2;
    for (int i = 1; i < n; i++) total -= lcp[i];
    return total;
}

225. GCD/LCM: Euclidean Algorithm

Greatest Common Divisor via Euclid: gcd(a,b) = gcd(b, a%b). Base gcd(a,0)=a. Time O(log min(a,b)). LCM via gcd: lcm(a,b) = a/gcd(a,b)*b to avoid overflow. GCD fundamental in fractions, modular arithmetic, cryptography.

int gcd(int a, int b) {
    while (b) {
        a %= b;
        swap(a, b);
    }
    return a;
}
long long lcm(int a, int b) {
    return 1LL * a / gcd(a, b) * b;
}
Time: O(log min(a,b))

226. GCD/LCM: Extended Euclidean

Extended Euclidean finds x,y such that ax+by=gcd(a,b). Used for modular inverse. Recursively: if b=0, x=1,y=0. Else solve b,a%b, then x=y', y=x'-floor(a/b)*y'. Bezout coefficients solve Diophantine equations.

int exgcd(int a, int b, int& x, int& y) {
    if (b == 0) {
        x = 1; y = 0;
        return a;
    }
    int x1, y1;
    int g = exgcd(b, a % b, x1, y1);
    x = y1;
    y = x1 - (a / b) * y1;
    return g;
}

228. GCD/LCM: Binary GCD

Binary GCD avoids modulo, faster for large ints. Use factors of 2: if a,b even, gcd=2*gcd(a/2,b/2). If a even, gcd(a/2,b). If both odd, gcd(|a-b|/2, min(a,b)). Shifts faster than %. Useful in high-performance code.

int binaryGCD(int a, int b) {
    if (!a || !b) return a | b;
    int shift = __builtin_ctz(a | b);
    a >>= __builtin_ctz(a);
    do {
        b >>= __builtin_ctz(b);
        if (a > b) swap(a, b);
        b -= a;
    } while (b);
    return a << shift;
}

234. Prime Sieves: Linear Sieve

Linear sieve O(n): each composite marked by smallest prime factor once. Store spf[i] = smallest prime factor. For each i, mark i*prime[j] where prime[j]≤spf[i]. Computes primes and spf simultaneously. Useful for fast factorization.

const int MAXN = 1e6;
int spf[MAXN+1];
vector<int> primes;
void linearSieve(int n) {
    for (int i = 2; i <= n; i++) {
        if (spf[i] == 0) {
            spf[i] = i;
            primes.push_back(i);
        }
        for (int j = 0; j < primes.size() && primes[j] <= spf[i] && i*primes[j] <= n; j++) {
            spf[i * primes[j]] = primes[j];
        }
    }
}
Time: O(n)

235. Prime Sieves: Segmented Sieve

Find primes in range [L,R] where R-L ≤1e6 but L,R ≤1e12. Sieve primes up to sqrt(R), then mark in [L,R]. Offset index i-L. Avoids memory for full range. Used for large ranges. Time O((R-L+1) log log R + sqrt(R) log log sqrt(R)).

vector<int> segmentedSieve(long long L, long long R) {
    long long lim = sqrt(R);
    vector<bool> mark(lim+1, true);
    vector<long long> basePrimes;
    for (long long i = 2; i <= lim; i++) {
        if (mark[i]) {
            basePrimes.push_back(i);
            for (long long j = i*i; j <= lim; j += i)
                mark[j] = false;
        }
    }
    vector<bool> isPrime(R-L+1, true);
    for (long long p : basePrimes) {
        long long start = max(p*p, (L+p-1)/p*p);
        for (long long j = start; j <= R; j += p)
            isPrime[j-L] = false;
    }
    if (L == 1) isPrime[0] = false;
    vector<int> res;
    for (int i = 0; i <= R-L; i++)
        if (isPrime[i]) res.push_back(L+i);
    return res;
}
Time: O((R-L+1) log log R)

249. Fast Exponentiation: Binary Exponentiation

Compute a^b in O(log b). Idea: a^13 = a^8*a^4*a^1. Iterate through bits of b. If bit set, multiply result. Square a each step. Works for modulo too. Generalizes to any associative operation: matrix pow, string pow.

long long binpow(long long a, long long b) {
    long long res = 1;
    while (b > 0) {
        if (b & 1) res *= a;
        a *= a;
        b >>= 1;
    }
    return res;
}
Time: O(log b)

251. Fast Exponentiation: Matrix Exponentiation

For linear recurrences: F_n = aF_{n-1}+bF_{n-2}. Represent as matrix [[a,b],[1,0]]^n * [F1,F0]. Computes F_n in O(k^3 log n) where k=matrix size. Useful for Fibonacci O(log n), path counts in graph, DP optimization. Combine with mod.

using Matrix = vector<vector<long long>>;
Matrix mul(Matrix& A, Matrix& B) {
    int n = A.size();
    Matrix C(n, vector<long long>(n));
    for (int i = 0; i < n; i++)
        for (int k = 0; k < n; k++)
            for (int j = 0; j < n; j++)
                C[i][j] = (C[i][j] + A[i][k] * B[k][j]) % MOD;
    return C;
}
Matrix pow(Matrix A, long long p) {
    int n = A.size();
    Matrix res(n, vector<long long>(n));
    for (int i = 0; i < n; i++) res[i][i] = 1;
    while (p) {
        if (p & 1) res = mul(res, A);
        A = mul(A, A);
        p >>= 1;
    }
    return res;
}
Time: O(k^3 log n)
