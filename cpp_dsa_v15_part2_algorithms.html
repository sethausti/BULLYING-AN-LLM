197Bubble Sort

Bubble Sort repeatedly steps through the list, compares adjacent elements and swaps them if they are in wrong order. The pass through the list is repeated until no swaps are needed. Larger elements bubble to the end with each pass. This is an in-place algorithm but inefficient for large datasets.

Time: O(n²) Space: O(1) Stable: Yes 
void bubbleSort(int arr[], int n) {
    for (int i = 0; i < n-1; i++) {
        for (int j = 0; j < n-i-1; j++) {
            if (arr[j] > arr[j+1]) {
                swap(arr[j], arr[j+1]);
            }
        }
    }
}

199Bubble Sort Optimized

The optimized version adds a flag to detect if any swap occurred in a pass. If no swaps happen, the array is already sorted and we can terminate early. This improves best case to O(n) when the array is already sorted. The optimization checks after each complete pass through the unsorted portion.

Best: O(n) Avg/Worst: O(n²) 
void bubbleSortOpt(int arr[], int n) {
    bool swapped;
    for (int i = 0; i < n-1; i++) {
        swapped = false;
        for (int j = 0; j < n-i-1; j++) {
            if (arr[j] > arr[j+1]) {
                swap(arr[j], arr[j+1]);
                swapped = true;
            }
        }
        if (!swapped) break;
    }
}

200Selection Sort

Selection Sort divides the array into sorted and unsorted regions. It repeatedly finds the minimum element from the unsorted portion and swaps it with the first unsorted element. This algorithm performs well on small lists and when memory writes are costly. It makes only O(n) swaps compared to O(n²) for Bubble Sort.

Time: O(n²) Space: O(1) Stable: No 
void selectionSort(int arr[], int n) {
    for (int i = 0; i < n-1; i++) {
        int minIdx = i;
        for (int j = i+1; j < n; j++) {
            if (arr[j] < arr[minIdx])
                minIdx = j;
        }
        swap(arr[minIdx], arr[i]);
    }
}

202Insertion Sort

Insertion Sort builds the final sorted array one element at a time. It iterates through the input, removing one element and finding its correct position in the sorted portion by shifting larger elements right. It's efficient for small datasets and nearly sorted arrays. The algorithm is adaptive and stable, working similarly to how we sort playing cards.

Best: O(n) Avg/Worst: O(n²) Stable: Yes 
void insertionSort(int arr[], int n) {
    for (int i = 1; i < n; i++) {
        int key = arr[i];
        int j = i - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j+1] = arr[j];
            j--;
        }
        arr[j+1] = key;
    }
}

204Merge Sort

Merge Sort is a divide-and-conquer algorithm that recursively splits the array into halves until single elements remain, then merges them back in sorted order. It guarantees O(n log n) time in all cases, making it reliable for large datasets. The merge operation is the key step where two sorted subarrays are combined into one sorted array.

Time: O(n log n) Space: O(n) Stable: Yes 
void mergeSort(int arr[], int l, int r) {
    if (l < r) {
        int m = l + (r-l)/2;
        mergeSort(arr, l, m);
        mergeSort(arr, m+1, r);
        merge(arr, l, m, r);
    }
}

205Merge Sort Divide

The divide step recursively breaks the problem into smaller subproblems. We find the middle point and recursively sort the left and right halves. This creates a recursion tree of depth log n. Base case occurs when subarray has 0 or 1 elements which are trivially sorted. The actual sorting happens during the merge phase, not the divide.

206Merge Sort Conquer

The merge function combines two sorted subarrays into a single sorted array. We use two pointers to track positions in each subarray and a temporary array to store the merged result. After one subarray is exhausted, we copy remaining elements from the other. Finally we copy the temp array back to the original array.

void merge(int arr[], int l, int m, int r) {
    int n1 = m - l + 1, n2 = r - m;
    int L[n1], R[n2];
    for(int i = 0; i < n1; i++) L[i] = arr[l+i];
    for(int j = 0; j < n2; j++) R[j] = arr[m+1+j];
    
    int i = 0, j = 0, k = l;
    while(i < n1 && j < n2)
        arr[k++] = (L[i] <= R[j]) ? L[i++] : R[j++];
    while(i < n1) arr[k++] = L[i++];
    while(j < n2) arr[k++] = R[j++];
}

208Quick Sort

Quick Sort picks a pivot element and partitions the array so elements less than pivot come before it, and greater elements after. It then recursively sorts the subarrays. Average case is O(n log n) but worst case O(n²) occurs on already sorted data with poor pivot choice. It's in-place but not stable. Randomized pivot selection helps avoid worst case.

Best/Avg: O(n log n) Worst: O(n²) Space: O(log n) 
void quickSort(int arr[], int low, int high) {
    if (low < high) {
        int pi = partition(arr, low, high);
        quickSort(arr, low, pi - 1);
        quickSort(arr, pi + 1, high);
    }
}

209Quick Sort Partition

Lomuto partition scheme uses last element as pivot. We maintain index i for elements smaller than pivot. For each element, if it's smaller than pivot, increment i and swap with current position. Finally swap pivot to position i+1. This ensures all elements left of pivot are smaller and right are larger. Hoare's partition is another efficient variant.

int partition(int arr[], int low, int high) {
    int pivot = arr[high];
    int i = low - 1;
    for (int j = low; j < high; j++) {
        if (arr[j] < pivot) {
            i++;
            swap(arr[i], arr[j]);
        }
    }
    swap(arr[i+1], arr[high]);
    return i + 1;
}

211Heap Sort

Heap Sort converts the array to a max-heap, then repeatedly extracts the maximum element by swapping root with last element and heapifying the reduced heap. A heap is a complete binary tree where parent is larger than children. Build-heap takes O(n) time, and each of n extractions takes O(log n), giving O(n log n) total. It's in-place but not stable.

Time: O(n log n) Space: O(1) Stable: No 
void heapSort(int arr[], int n) {
    for (int i = n/2-1; i >= 0; i--)
        heapify(arr, n, i);
    for (int i = n-1; i > 0; i--) {
        swap(arr[0], arr[i]);
        heapify(arr, i, 0);
    }
}

212Heapify Process

Heapify maintains the max-heap property for a subtree rooted at index i. It assumes left and right subtrees are already heaps. We compare the node with its children and swap with the largest child if needed, then recursively heapify the affected subtree. This sift-down operation takes O(log n) time where n is the size of the heap.

void heapify(int arr[], int n, int i) {
    int largest = i;
    int l = 2*i + 1;
    int r = 2*i + 2;
    
    if (l < n && arr[l] > arr[largest])
        largest = l;
    if (r < n && arr[r] > arr[largest])
        largest = r;
    if (largest != i) {
        swap(arr[i], arr[largest]);
        heapify(arr, n, largest);
    }
}

213Counting Sort

Counting Sort is a non-comparison sort for integers with small range k. It counts occurrences of each value, computes prefix sums for positions, then places elements in output array. It achieves O(n+k) time which is linear when k=O(n). The algorithm is stable and works well for sorting objects by integer keys like grades or ages.

Time: O(n+k) Space: O(n+k) Stable: Yes 
void countingSort(int arr[], int n) {
    int maxVal = *max_element(arr, arr+n);
    int count[maxVal+1] = {0};
    
    for(int i = 0; i < n; i++)
        count[arr[i]]++;
    for(int i = 1; i <= maxVal; i++)
        count[i] += count[i-1];
        
    int output[n];
    for(int i = n-1; i >= 0; i--) {
        output[count[arr[i]]-1] = arr[i];
        count[arr[i]]--;
    }
    for(int i = 0; i < n; i++)
        arr[i] = output[i];
}

215STL sort()

C++ STL sort implements Introsort - a hybrid of Quick Sort, Heap Sort, and Insertion Sort. It starts with Quick Sort, switches to Heap Sort when recursion depth exceeds log n to avoid worst case O(n²), and uses Insertion Sort for small subarrays. This guarantees O(n log n) worst case. Default uses operator< for comparison.

#include <algorithm>
#include <vector>
using namespace std;

vector<int> v = {5,1,4,2,8};
sort(v.begin(), v.end()); // [1,2,4,5,8]
sort(v.rbegin(), v.rend()); // [8,5,4,2,1]

// For array
int arr[] = {5,1,4,2,8};
sort(arr, arr + 5);

216Custom Compare

STL sort accepts a third parameter for custom comparison logic. This can be a function pointer, lambda, or functor returning true if first argument should come before second. Common uses include sorting pairs by second element, descending order, or custom objects. The comparator must define a strict weak ordering to avoid undefined behavior.

vector<pair<int,int>> v = {{5,1},{1,4},{4,2}};

// Sort by second element
sort(v.begin(), v.end(), [](auto &a, auto &b) {
    return a.second < b.second;
}); // [{5,1},{4,2},{1,4}]

// Sort descending
sort(v.begin(), v.end(), greater<int>());

217Sort Stability

A stable sort preserves the relative order of equal elements. Bubble, Insertion, Merge, and Counting sorts are stable. Quick, Heap, and Selection sorts are not stable. For objects with multiple keys, stable sort allows sorting by one key then another. STL provides stable_sort() which is stable but uses O(n) extra space and may be slower than sort().

vector<pair<int,string>> v = {{2,"a"},{1,"b"},{2,"c"}};

// Unstable sort may give: [{1,"b"},{2,"c"},{2,"a"}]
sort(v.begin(), v.end());

// Stable sort gives: [{1,"b"},{2,"a"},{2,"c"}]
stable_sort(v.begin(), v.end());

PHASE 2: SEARCHING ALGORITHMS

219Linear Search

Linear Search sequentially checks each element until the target is found or the end is reached. It works on unsorted and sorted data with no preprocessing required. Best case O(1) when element is first, worst case O(n) when element is last or absent. It's simple but inefficient for large datasets. Use when data is unsorted and small, or searched infrequently.

Time: O(n) Space: O(1) 
int linearSearch(int arr[], int n, int x) {
    for (int i = 0; i < n; i++)
        if (arr[i] == x)
            return i;
    return -1;
}

220Binary Search

Binary Search finds a target in a sorted array by repeatedly dividing the search interval in half. Compare target with middle element: if equal return index, if smaller search left half, if larger search right half. This eliminates half the remaining elements each iteration. Requires sorted data but gives logarithmic search time. Much faster than linear search for large n.

Time: O(log n) Space: O(1) Req: Sorted 
int binarySearch(int arr[], int l, int r, int x) {
    while (l <= r) {
        int m = l + (r - l) / 2;
        if (arr[m] == x) return m;
        if (arr[m] < x) l = m + 1;
        else r = m - 1;
    }
    return -1;
}

222BS Edge Cases

Common Binary Search pitfalls: integer overflow in (l+r)/2 - use l+(r-l)/2 instead. Infinite loops from incorrect boundary updates - ensure l=m+1 or r=m-1. Off-by-one errors in loop condition - use l<=r for inclusive bounds. Empty array check: return -1 if n==0. Target not found handling. Duplicates require lower/upper bound variants to find first/last occurrence.

// Safe mid calculation
int mid = left + (right - left) / 2;

// Inclusive bounds
while (left <= right) {
    // ...
    if (arr[mid] < target) left = mid + 1;
    else right = mid - 1;
}

223Lower Bound

Lower bound finds the first element not less than target - the leftmost insertion point to maintain sorted order. If all elements are smaller, returns n. If target exists, returns index of first occurrence. Implementation modifies binary search: when arr[mid]>=target, record mid and search left. This is useful for finding first occurrence of duplicates or insertion points.

int lower_bound(int arr[], int n, int x) {
    int l = 0, r = n;
    while (l < r) {
        int m = l + (r - l) / 2;
        if (arr[m] < x) l = m + 1;
        else r = m;
    }
    return l;
}
// [1,2,4,4,5,8], x=4 → returns 2

224Upper Bound

Upper bound finds the first element greater than target - the rightmost insertion point. If all elements are less or equal, returns n. If target exists, returns index after last occurrence. The only difference from lower_bound is using arr[mid]<=x instead of arr[mid] 

int upper_bound(int arr[], int n, int x) {
    int l = 0, r = n;
    while (l < r) {
        int m = l + (r - l) / 2;
        if (arr[m] <= x) l = m + 1;
        else r = m;
    }
    return l;
}
// [1,2,4,4,5,8], x=4 → returns 4

225BS First/Last Occur

To find first or last occurrence in sorted array with duplicates, modify binary search. For first occurrence: when found, continue searching left half by setting r=mid-1. For last: search right half with l=mid+1. Store the answer whenever target is found. Alternative: use lower_bound for first, upper_bound-1 for last after checking if target exists.

int firstOccur(int arr[], int n, int x) {
    int l = 0, r = n-1, res = -1;
    while (l <= r) {
        int m = l + (r-l)/2;
        if (arr[m] == x) {
            res = m; r = m-1; // search left
        } else if (arr[m] < x) l = m+1;
        else r = m-1;
    }
    return res;
}

226BS on Answer

Binary Search on Answer applies BS to search space of possible answers, not array indices. If we can verify if a value x is valid in O(f(n)) and the valid range has monotonic property, we can BS the answer in O(f(n) log(max-min)). Classic problems: minimum capacity to ship packages, smallest divisor, square root, or allocation problems. Key is defining the check function.

// Find min x such that check(x) is true
int lo = 1, hi = 1e9, ans = -1;
while(lo <= hi) {
    int mid = lo + (hi-lo)/2;
    if(check(mid)) {
        ans = mid;
        hi = mid-1; // try smaller
    } else {
        lo = mid+1;
    }
}

227STL Binary Search

STL provides binary_search() returning bool indicating if element exists. It requires sorted range and uses operator<. For index, use lower_bound or upper_bound. All operate in O(log n) time. These functions work on any random access iterators like vector, deque, or plain arrays. For containers like set/map, use their member functions which are also O(log n).

#include <algorithm>
vector<int> v = {1,2,4,5,8};

bool exists = binary_search(v.begin(), v.end(), 4); // true

auto it = lower_bound(v.begin(), v.end(), 4); 
int idx = it - v.begin(); // 2

auto it2 = upper_bound(v.begin(), v.end(), 4);
int count = it2 - lower_bound(v.begin(), v.end(), 4); // 1

228STL lower_bound

STL lower_bound returns iterator to first element not less than val, or end() if all elements are less. For arrays: lower_bound(arr, arr+n, x) - arr gives index. Upper_bound returns iterator to first element greater than val. equal_range returns pair of both. These functions enable efficient range queries, counting occurrences, and finding insertion points in sorted containers.

int arr[] = {1,2,4,4,5,8};
int n = 6;

int lb = lower_bound(arr, arr+n, 4) - arr; // 2
int ub = upper_bound(arr, arr+n, 4) - arr; // 4
int cnt = ub - lb; // 2 occurrences

auto range = equal_range(arr, arr+n, 4);
// range.first = lb, range.second = ub

229Ternary Search

Ternary Search finds maximum or minimum of a unimodal function - one that increases then decreases or vice versa. Divide range into three parts using two mids: m1=l+(r-l)/3, m2=r-(r-l)/3. Compare f(m1) and f(m2) to eliminate one third of search space. Each iteration reduces range by 1/3 vs 1/2 in binary search. Useful for optimization problems on continuous domains.

Time: O(log₃ n) Req: Unimodal 
double ternarySearch(double l, double r) {
    while (r - l > 1e-9) {
        double m1 = l + (r-l)/3;
        double m2 = r - (r-l)/3;
        if (f(m1) < f(m2))
            l = m1;
        else
            r = m2;
    }
    return f(l);
}

We narrow down: m1=2 gives f=8, m2=4 gives f=8, eliminate based on comparison. Continue until interval is tiny.

232Graph Intro

A graph G=(V,E) consists of vertices V and edges E connecting pairs of vertices. Graphs model relationships: social networks, road maps, dependencies. Key terms: vertex/node, edge, degree, path, cycle, connected component. Graphs can be directed or undirected, weighted or unweighted, cyclic or acyclic. Understanding graph properties determines which algorithms to apply.

V: vertices E: edges

233Graph Types

Directed graphs have ordered edges (u→v), like Twitter follows. Undirected have unordered edges (u-v), like Facebook friends. Weighted graphs assign values to edges, like road distances. DAG is Directed Acyclic Graph with no cycles, used for scheduling. Complete graph has edge between every pair. Bipartite graph vertices split into two sets with edges only between sets.

Adjacency matrix uses V×V 2D array where mat[i][j]=1 if edge i→j exists, 0 otherwise. For weighted graphs, store weight instead of 1. Space O(V²) which is wasteful for sparse graphs. 236BFS Algorithm

Breadth-First Search explores graph level by level from a source. Uses a queue to visit all neighbors before moving to next level. BFS finds shortest path in unweighted graphs and traverses in radius order. It marks visited nodes to avoid cycles. Time O(V+E) as each vertex and edge processed once. Space O(V) for queue and visited array.

Time: O(V+E) Space: O(V) 
void bfs(int start, vector<int> adj[], int V) {
    vector<bool> vis(V, false);
    queue<int> q;
    q.push(start);
    vis[start] = true;
    
    while(!q.empty()) {
        int u = q.front(); q.pop();
        // process u
        for(int v : adj[u]) {
            if(!vis[v]) {
                vis[v] = true;
                q.push(v);
            }
        }
    }
}

242DFS Code Iterative

Iterative DFS uses explicit stack to avoid recursion limit. We push nodes and process when popped. To mimic recursive behavior, push neighbors in reverse order. Mark visited when pushing or popping depending on use case. Iterative version handles deep graphs without stack overflow. Time complexity remains O(V+E).

void dfsIter(int s, vector<int> adj[], int n) {
    vector<bool> vis(n, false);
    stack<int> st;
    st.push(s);
    
    while(!st.empty()) {
        int u = st.top(); st.pop();
        if(vis[u]) continue;
        vis[u] = true;
        
        for(auto it = adj[u].rbegin(); it != adj[u].rend(); ++it) {
            if(!vis[*it]) st.push(*it);
        }
    }
}

243Connected Components

In an undirected graph, connected components are maximal sets of vertices where each pair has a path. Run DFS/BFS from each unvisited vertex - each run discovers one component. In undirected graphs, cycle exists if DFS finds a visited neighbor that's not the parent. In directed graphs, cycle exists if we encounter a vertex in current recursion stack - use gray coloring.         }

}

245Bipartite Check

A graph is bipartite if vertices can be colored with 2 colors such that no edge connects same color vertices. Run BFS/DFS and try to 2-color. If we find an edge between same colors, graph is not bipartite. Bipartite graphs have no odd-length cycles. This check is O(V+E). Applications: matching, scheduling conflicts.

bool isBipartite(vector<int> adj[], int n) {
    vector<int> color(n, -1);
    queue<int> q;
    for(int i = 0; i < n; i++) {
        if(color[i] == -1) {
            q.push(i); color[i] = 0;
            while(!q.empty()) {
                int u = q.front(); q.pop();
                for(int v : adj[u]) {
                    if(color[v] == -1) {
                        color[v] = 1 - color[u];
                        q.push(v);
                    } else if(color[v] == color[u])
                        return false;
                }
            }
        }
    }
    return true;
}

248Dijkstra Code

Implementation using priority_queue for min-heap. We use greater<> to make it min-heap. Store {distance, vertex} pairs. Skip outdated entries where current dist[v] < d from queue. Edge relaxation: if dist[u]+w < dist[v], update and push. Parent array can reconstruct paths. For dense graphs, array-based O(V²) may be faster than heap version.

vector<int> dijkstra(int s, vector<pair<int,int>> adj[], int n) {
    vector<int> dist(n, 1e9);
    priority_queue<pii, vector<pii>, greater<pii>> pq;
    dist[s] = 0;
    pq.push({0, s});
    
    while(!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if(d > dist[u]) continue;
        for(auto [v, w] : adj[u]) {
            if(dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.push({dist[v], v});
            }
        }
    }
    return dist;
}

250Kruskal Algorithm

Kruskal's algorithm sorts all edges by weight and greedily adds smallest edge that doesn't form a cycle. Uses Disjoint Set Union to detect cycles efficiently. If edge connects two different components, add it and union the sets. Stop after V-1 edges added. Sorting dominates time O(E log E). Best for sparse graphs. Correctness follows from cut property of MSTs.

Time: O(E log E) Space: O(V) 
struct Edge { int u, v, w; };
bool cmp(Edge a, Edge b) { return a.w < b.w; }

int kruskal(vector<Edge>& edges, int n) {
    sort(edges.begin(), edges.end(), cmp);
    DSU dsu(n);
    int mst = 0, cnt = 0;
    for(auto e : edges) {
        if(dsu.find(e.u) != dsu.find(e.v)) {
            dsu.unite(e.u, e.v);
            mst += e.w;
            if(++cnt == n-1) break;
        }
    }
    return mst;
}

251DSU Find Union

Disjoint Set Union supports find and union in nearly O(1) amortized time. Uses path compression in find to flatten tree, and union by rank/size to keep tree shallow. Find returns representative of set. Union merges two sets. Essential for Kruskal and dynamic connectivity. Initialize each element as its own parent with rank 0.

struct DSU {
    vector<int> par, sz;
    DSU(int n) : par(n), sz(n,1) {
        iota(par.begin(), par.end(), 0);
    }
    int find(int x) {
        return x == par[x] ? x : par[x] = find(par[x]);
    }
    bool unite(int x, int y) {
        x = find(x), y = find(y);
        if(x == y) return false;
        if(sz[x] < sz[y]) swap(x, y);
        par[y] = x; sz[x] += sz[y];
        return true;
    }
};

254Prim Algorithm

Prim's algorithm grows MST from a source vertex. Maintain set of vertices in MST and priority queue of edges crossing the cut. Repeatedly add minimum weight edge connecting MST to new vertex. Similar to Dijkstra but key is edge weight not path distance. Efficient for dense graphs with adjacency matrix O(V²) or heap O(E log V). Works by cut property.

Time: O(E log V) Space: O(V) 
int prim(vector<pair<int,int>> adj[], int n) {
    vector<bool> inMST(n, false);
    priority_queue<pii, vector<pii>, greater<pii>> pq;
    pq.push({0, 0}); // {weight, vertex}
    int mst = 0;
    
    while(!pq.empty()) {
        auto [w, u] = pq.top(); pq.pop();
        if(inMST[u]) continue;
        inMST[u] = true;
        mst += w;
        for(auto [v, wt] : adj[u]) {
            if(!inMST[v])
                pq.push({wt, v});
        }
    }
    return mst;
}

256TopoSort DFS

DFS-based topological sort pushes vertices onto stack after visiting all descendants. When DFS finishes for a vertex, all vertices reachable from it are already processed. Reverse of finish times gives topological order. If back edge found during DFS, graph has cycle and topo sort impossible. Stack stores result in reverse order.

void dfsTopo(int u, vector<int> adj[], vector<bool>& vis, stack<int>& st) {
    vis[u] = true;
    for(int v : adj[u])
        if(!vis[v])
            dfsTopo(v, adj, vis, st);
    st.push(u); // add after all descendants
}

vector<int> topoSort(int n, vector<int> adj[]) {
    vector<bool> vis(n, false);
    stack<int> st;
    for(int i = 0; i < n; i++)
        if(!vis[i]) dfsTopo(i, adj, vis, st);
    
    vector<int> order;
    while(!st.empty()) {
        order.push_back(st.top());
        st.pop();
    }
    return order;
}

257Kahn's Algorithm

Kahn's algorithm uses in-degrees. Start with vertices having in-degree 0 - no dependencies. Remove vertex and decrease in-degree of neighbors. Add new zero in-degree vertices to queue. Process until queue empty. If all vertices processed, we have valid topo order; else cycle exists. This is BFS-like and naturally detects cycles by counting processed nodes.

Time: O(V+E) Space: O(V) 
vector<int> kahn(int n, vector<int> adj[]) {
    vector<int> indeg(n, 0);
    for(int u = 0; u < n; u++)
        for(int v : adj[u])
            indeg[v]++;
    
    queue<int> q;
    for(int i = 0; i < n; i++)
        if(indeg[i] == 0) q.push(i);
    
    vector<int> order;
    while(!q.empty()) {
        int u = q.front(); q.pop();
        order.push_back(u);
        for(int v : adj[u])
            if(--indeg[v] == 0)
                q.push(v);
    }
    return order.size() == n ? order : vector<int>();
}

262Bellman-Ford Algorithm

Bellman-Ford computes shortest paths from source in graphs with negative edge weights. It relaxes all edges V-1 times, ensuring shortest paths with up to V-1 edges are found. A V-th relaxation detecting changes indicates negative cycle. Slower than Dijkstra O(VE) but handles negative weights. Used in distance-vector routing protocols. Returns false if negative cycle reachable from source.

Time: O(VE) Space: O(V) 
bool bellmanFord(int s, vector<Edge>& edges, int n, vector<int>& dist) {
    dist.assign(n, 1e9);
    dist[s] = 0;
    for(int i = 0; i < n-1; i++) {
        for(auto [u, v, w] : edges) {
            if(dist[u] != 1e9 && dist[u] + w < dist[v])
                dist[v] = dist[u] + w;
        }
    }
    // Check negative cycle
    for(auto [u, v, w] : edges)
        if(dist[u] != 1e9 && dist[u] + w < dist[v])
            return false; // negative cycle
    return true;
}

263Floyd-Warshall Algorithm

Floyd-Warshall computes shortest paths between all pairs of vertices. Uses dynamic programming: for each intermediate vertex k, update distance[i][j] = min(distance[i][j], distance[i][k] + distance[k][j]). Handles negative edges but no negative cycles. Simple O(V³) implementation with three nested loops. Space O(V²) for distance matrix. Good for dense graphs or multiple queries.

Time: O(V³) Space: O(V²) 
void floydWarshall(vector<vector<int>>& dist, int n) {
    for(int k = 0; k < n; k++) {
        for(int i = 0; i < n; i++) {
            for(int j = 0; j < n; j++) {
                if(dist[i][k] != 1e9 && dist[k][j] != 1e9)
                    dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]);
            }
        }
    }
    // Check negative cycle: dist[i][i] < 0
}

Edge u-v is bridge if low[v] > disc[u], meaning no back-edge from v or its descendants to u or ancestors. Bridges critical for network reliability. Single DFS O(V+E).

void findBridges(int u, int parent, vector<int> adj[]) {
    static int time = 0;
    disc[u] = low[u] = ++time;
    for(int v : adj[u]) {
        if(v == parent) continue;
        if(!disc[v]) {
            findBridges(v, u, adj);
            low[u] = min(low[u], low[v]);
            if(low[v] > disc[u])
                bridges.push_back({u,v});
        } else {
            low[u] = min(low[u], disc[v]);
        }
    }
}

269Articulation Points

Articulation point (cut vertex) is vertex whose removal increases components. Root is AP if it has ≥2 children in DFS tree. Non-root u is AP if it has child v with low[v] ≥ disc[u], meaning no back-edge from subtree of v to ancestor of u. Found with DFS similar to bridges. Critical for network robustness analysis.

void findAP(int u, int parent, vector<int> adj[]) {
    static int time = 0;
    disc[u] = low[u] = ++time;
    int children = 0;
    for(int v : adj[u]) {
        if(v == parent) continue;
        if(!disc[v]) {
            children++;
            findAP(v, u, adj);
            low[u] = min(low[u], low[v]);
            if(parent != -1 && low[v] >= disc[u])
                isAP[u] = true;
        } else {
            low[u] = min(low[u], disc[v]);
        }
    }
    if(parent == -1 && children > 1)
        isAP[u] = true;
}

271Hamiltonian Path

Hamiltonian Path visits every vertex exactly once. Hamiltonian Cycle returns to start. No efficient algorithm known - NP-Complete problem. Naive backtracking O(N!). Used in traveling salesman approximations. Dirac's theorem: if each vertex degree ≥ n/2, Hamiltonian cycle exists. Ore's theorem: if deg(u)+deg(v) ≥ n for non-adjacent u,v, cycle exists.

// Backtracking for Hamiltonian Path
bool hamiltonianPath(vector<int> adj[], int n, 
                     vector<int>& path, int pos) {
    if(pos == n) return true;
    for(int v : adj[path[pos-1]]) {
        if(!used[v]) {
            used[v] = true;
            path[pos] = v;
            if(hamiltonianPath(adj, n, path, pos+1))
                return true;
            used[v] = false;
        }
    }
    return false;
}

272Graph Coloring

Graph coloring assigns colors to vertices such that adjacent vertices have different colors. Chromatic number χ(G) is minimum colors needed. Bipartite graphs have χ=2. Planar graphs have χ≤4. NP-Hard for general graphs but greedy coloring gives upper bound Δ+1 where Δ is max degree. Welsh-Powell orders by degree. Used in scheduling, register allocation, map coloring.

// Greedy coloring
vector<int> greedyColor(vector<int> adj[], int n) {
    vector<int> result(n, -1);
    result[0] = 0;
    vector<bool> available(n, false);
    
    for(int u = 1; u < n; u++) {
        for(int v : adj[u])
            if(result[v] != -1)
                available[result[v]] = true;
        int cr;
        for(cr = 0; cr < n; cr++)
            if(!available[cr]) break;
        result[u] = cr;
        fill(available.begin(), available.end(), false);
    }
    return result;
}

273Maximum Flow

Max Flow finds maximum flow from source to sink in flow network with edge capacities. Ford-Fulkerson uses augmenting paths O(E·max_flow). Edmonds-Karp uses BFS for shortest augmenting path O(VE²). Dinic's algorithm O(V²E) faster in practice. Min-Cut Max-Flow theorem: max flow equals min cut capacity. Applications: bipartite matching, network reliability, image segmentation.

// Edmonds-Karp BFS to find augmenting path
int bfs(int s, int t, vector<int> adj[], int cap[][MAX]) {
    fill(parent, parent+MAX, -1);
    queue<pair<int,int>> q;
    q.push({s, 1e9});
    while(!q.empty()) {
        auto [u, flow] = q.front(); q.pop();
        for(int v : adj[u]) {
            if(parent[v] == -1 && cap[u][v] > 0) {
                parent[v] = u;
                int new_flow = min(flow, cap[u][v]);
                if(v == t) return new_flow;
                q.push({v, new_flow});
            }
        }
    }
    return 0;
}

286Bidirectional Search

Bidirectional BFS runs search from both start and goal simultaneously, meeting in middle. Reduces search space from O(b^d) to O(b^(d/2)) where b is branching factor, d is distance. Both frontiers use BFS. Stop when frontiers meet. Useful when both start and goal known. Implementation maintains two queues and visited sets. Cuts exponential factor in half.

int bidirectionalBFS(int s, int t, vector<int> adj[]) {
    if(s == t) return 0;
    queue<int> q1, q2;
    unordered_set<int> v1, v2;
    q1.push(s); v1.insert(s);
    q2.push(t); v2.insert(t);
    int dist = 0;
    while(!q1.empty() && !q2.empty()) {
        dist++;
        if(expand(q1, v1, v2, adj)) return dist;
        dist++;
        if(expand(q2, v2, v1, adj)) return dist;
    }
    return -1;
}

2870-1 BFS

0-1 BFS finds shortest path when edge weights are only 0 or 1. Uses deque: weight 0 edges pushed to front, weight 1 to back. Maintains monotonic queue where distances are non-decreasing. Each vertex processed at most twice. Time O(V+E), faster than Dijkstra O(E log V). Useful in grid problems with obstacles or special moves.

vector<int> bfs01(int s, vector<pair<int,int>> adj[], int n) {
    vector<int> dist(n, 1e9);
    deque<int> dq;
    dist[s] = 0;
    dq.push_back(s);
    while(!dq.empty()) {
        int u = dq.front(); dq.pop_front();
        for(auto [v, w] : adj[u]) {
            if(dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                if(w == 0) dq.push_front(v);
                else dq.push_back(v);
            }
        }
    }
    return dist;
}

297LCA Binary Lifting

Lowest Common Ancestor of two nodes is deepest node that has both as descendants. Binary lifting preprocesses O(n log n) to answer queries O(log n). Precompute up[v][j] = 2^j-th ancestor of v. For query, lift deeper node to same level, then binary search upward until parents differ. Used in tree queries, distance queries: dist(u,v) = depth[u]+depth[v]-2*depth[lca].

Preprocess: O(n log n) Query: O(log n) 
int lca(int u, int v) {
    if(depth[u] < depth[v]) swap(u,v);
    int diff = depth[u] - depth[v];
    for(int i = 0; i < LOG; i++)
        if(diff & (1<<i)) u = up[u][i];
    if(u == v) return u;
    for(int i = LOG-1; i >= 0; i--)
        if(up[u][i] != up[v][i])
            u = up[u][i], v = up[v][i];
    return up[u][0];
}

306Traveling Salesman Problem

TSP: find shortest Hamiltonian cycle visiting all vertices exactly once. NP-Hard, no polynomial solution known. DP with bitmask O(n²·2ⁿ): dp[mask][i] = min cost to visit vertices in mask, ending at i. Held-Karp algorithm. Approximation: MST-based 2-approximation for metric TSP. Heuristics: nearest neighbor, Christofides 1.5-approx. Branch and bound for exact solutions.

Exact: O(n²·2ⁿ) NP-Hard 
// DP TSP O(n²2ⁿ)
vector<vector<int>> dp(1<<n, vector<int>(n, 1e9));
dp[1][0] = 0;
for(int mask = 1; mask < (1<<n); mask++) {
    for(int u = 0; u < n; u++) {
        if(!(mask & (1<<u))) continue;
        for(int v = 0; v < n; v++) {
            if(mask & (1<<v)) continue;
            dp[mask | (1<<v)][v] = min(dp[mask | (1<<v)][v], 
                                        dp[mask][u] + dist[u][v]);
        }
    }
}

308Maximum Independent Set

Independent Set: vertices with no edges between them. Maximum IS is NP-Hard. For trees: DP O(n), dp[u][0/1] = max size excluding/including u. For bipartite: König's theorem: |Max Matching| = |Min Vertex Cover|, so |Max IS| = n - |Max Matching|. General graphs: backtracking or approximation. Complement of vertex cover. Used in scheduling, wireless networks.

// Tree Maximum Independent Set
pair<int,int> dfs(int u, int p, vector<int> adj[]) {
    int excl = 0, incl = 1;
    for(int v : adj[u]) {
        if(v == p) continue;
        auto [e, i] = dfs(v, u, adj);
        excl += max(e, i);
        incl += e;
    }
    return {excl, incl};
}

309Vertex Cover

Vertex Cover: set of vertices such that each edge has at least one endpoint in set. Minimum VC is NP-Hard. For bipartite graphs: König's theorem reduces to max matching. For trees: greedy or DP. 2-approximation: pick any edge, add both endpoints, remove incident edges, repeat. Complement of independent set. VC + IS = V for any graph. Used in network monitoring.

// 2-approximation for vertex cover
unordered_set<int> vc;
for(auto [u,v] : edges) {
    if(!vc.count(u) && !vc.count(v)) {
        vc.insert(u);
        vc.insert(v);
    }
}
